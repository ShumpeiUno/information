# Quantum Daily

量子コンピューティング関連の公開情報を、通勤中に25〜30分で読める日本語ブリーフへ整理する自動配信です。

## 閲覧先

- [最新の日次版](CURRENT.md)
- [最新の週末版](WEEKEND.md)
- [過去号](archive/)
- [全文Atomフィード](feed.xml)

Even G2では、GitHubの最新号をWebリーダーで開くか、AtomフィードをEven HubのRSSリーダーへ登録します。Atomの各エントリーには要約だけでなく本文全体を収録します。

## 配信時刻

- 月曜日から金曜日の06:30 JST: 前回号以降のQuantum Daily
- 金曜日20:30 JST: 週間再評価と週末の精読候補
- 土曜日・日曜日: 朝の新規配信なし
- 月曜日: 金曜日夜以降の週末分を回収

## 対象

量子アルゴリズム、量子振幅推定、量子Monte Carlo、量子金融、Early-FTQC、量子誤り訂正、論理量子ビット、実機・ベンチマーク、資源見積り、耐量子暗号、暗号アジリティ、金融機関・決済基盤への含意を重点的に扱います。金融に直接関係しなくても、学術上または技術上重要な量子情報科学の進展を含めます。

## 評価方針

原論文、標準化機関、規制当局、研究機関の一次資料を優先します。査読論文、プレプリント、企業発表、報道を区別し、実機かシミュレーションか、比較対象が妥当か、コード・データ・誤差評価があるかを確認します。同じ成果に関する広報と報道は1件へ統合します。

## Google DocsとGmail

`google-apps-script/Code.gs`は、最新号を固定Google Docsへ反映し、同じ本文をGmailへ送る任意の連携スクリプトです。GitHub Actions側はWebhook URLと共有シークレットが設定されている場合だけ自動同期します。設定方法は[Google連携手順](google-apps-script/SETUP.md)に記載しています。
